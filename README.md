# Malaria in Africa: Burden and Drug-Resistance Genes

## Goal
I want to understand why malaria is still a major threat in Africa and
explore genes linked to antimalarial drug resistance.

## Planned projects
1. Malaria burden in Africa (cases and deaths over time)
2. Drug-resistance genes in Plasmodium falciparum (pfcrt, kelch13)

## Data sources
- WHO Global Health Observatory
- Our World in Data
- NCBI / PlasmoDB / MalariaGEN

## Tools
Python (pandas, matplotlib, Biopython), R, Linux

## Status
In progress. I am learning as I build this.

Biotechnology graduate from Rwanda interested in bioinformatics.
